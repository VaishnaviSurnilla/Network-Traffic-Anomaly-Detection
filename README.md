# Network-Traffic-Anomaly-Detection
This project simulates large-scale cloud network monitoring by analyzing network flow data and detecting anomalies using machine learning.

# Dataset
UNSW-NB15 dataset (public cybersecurity dataset)

# Features
1. Network telemetry processing using Pandas
2. Feature engineering for traffic analysis
3. Anomaly detection using Isolation Forest
4. Visualization of abnormal traffic patterns

# Tech Stack
Python, Pandas, Scikit-learn, Matplotlib

# Results
1. Successfully detected anomalous traffic patterns
2. Simulated real-world network monitoring pipeline
